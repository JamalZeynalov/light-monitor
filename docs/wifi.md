# Wi-Fi з телефона й перший тест

## Перше підключення

1. Подайте живлення на прошиту плату. У списку Wi-Fi телефона знайдіть **LightMonitor-Setup**.
2. Підключіться з паролем `SETUP_AP_PASSWORD`, який ви записали в `config.h`.
3. Залишайтеся в цій мережі, навіть якщо телефон пише «без інтернету». Якщо вікно налаштування не відкрилося, зайдіть на **http://192.168.4.1**.
4. Виберіть **Configure WiFi**, свою мережу **2.4 GHz**, введіть пароль роутера та натисніть **Save**.
5. Поверніть телефон до домашнього Wi-Fi. Плата збереже налаштування та почне надсилати сигнали.

Портал працює до 3 хвилин. Якщо не встигли, плата повторить запуск і знову відкриє його, якщо не зможе підключитися до роутера. На iPhone за потреби виберіть залишатися в мережі без інтернету.

## Як побачити стан

У тому самому домашньому Wi-Fi відкрийте **http://light-monitor.local**. Сторінка показує підключення, IP, час після успішного сигналу та останній HTTP-код.

Якщо `.local` не працює, знайдіть `light-monitor` у списку пристроїв роутера та відкрийте його IP через `http://`. IP також видно в Arduino IDE → **Tools → Serial Monitor**, швидкість **115200 baud**.

HTTP `200` означає, що сервер прийняв heartbeat. Червона лампочка означає лише живлення. Локальна сторінка доступна в домашній мережі; віддалено ви отримуєте Telegram-сповіщення.

## Якщо змінюєте роутер

Коли збережена мережа недоступна, плата відкриває **LightMonitor-Setup** після спроби підключення. Повторіть налаштування телефоном.

Якщо старий роутер доступний, на вже запущеній платі утримуйте **BOOT 3 секунди** й відпустіть. Це відкриє портал. Не затискайте BOOT під час подачі живлення: так вмикається режим запису прошивки.

Зберігається остання налаштована мережа. Звичайне вимкнення живлення її не стирає.

## Якщо зв’язок пропав

| Ситуація | Поведінка |
| --- | --- |
| Зник Wi-Fi | Автоматичне перепідключення; після хвилини невдач знову запускається спроба підключення з порталом налаштування |
| Wi-Fi є, сервер недоступний | Плата залишається в мережі й повторює запит через 15 секунд після невдачі |
| Зникло живлення | Плата вимикається; після повернення запускається сама |
| Роутер ще завантажується | Плата продовжує спроби; очікування порталу може додати до 3 хвилин перед наступною спробою |

Сервер бачить тільки наявність або відсутність сигналів. Він не визначає, чи пропало світло, Wi-Fi або інтернет.

## Перевірка вимкнення

1. Переконайтеся на локальній сторінці, що сервер прийняв сигнал.
2. Від’єднайте USB-живлення плати. Не надсилайте heartbeat з Python-утиліти під час тесту: він теж підтримує стан «світло є».
3. Приблизно через 2–3 хвилини від останнього сигналу очікуйте сповіщення про вимкнення. Затримки Cloudflare чи Telegram можуть збільшити цей час.
4. Увімкніть плату знову. Після Wi-Fi, синхронізації часу й успішного запиту має прийти сповіщення про відновлення.

Найперше підключення до нового сервера проходить без повідомлення. Це нормально: ще не було переходу зі стану «світла немає».
