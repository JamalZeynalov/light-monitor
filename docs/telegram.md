# Telegram і локальна утиліта

## Створіть бота

1. Відкрийте офіційного [@BotFather](https://t.me/BotFather) у Telegram.
2. Надішліть `/newbot`, задайте назву та username, що закінчується на `bot`.
3. Збережіть виданий токен. Він знадобиться у Cloudflare та локальному `.env`.

Для особистих сповіщень відкрийте свого бота й натисніть **Start**. Для групи додайте бота до учасників і дозвольте йому писати повідомлення. Адміністраторські права для звичайної групи не потрібні, якщо правила групи дозволяють надсилання.

## Підготуйте утиліту

Потрібен Python 3.10 або новіший. Термінал має бути відкритий у розпакованій папці проєкту.

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
.venv/bin/python setup_helper.py
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .env.example .env
.venv\Scripts\python setup_helper.py
```

Відкрийте `.env` у текстовому редакторі та заповніть `TELEGRAM_BOT_TOKEN`. На macOS приховані файли показує **Cmd+Shift+.**. Після зміни `.env` перезапустіть утиліту. У macOS після встановлення залежностей також можна запускати `run.command` подвійним натисканням.

## Отримайте ID і ключ плати

1. У групі надішліть `/start@USERNAME_ВАШОГО_БОТА`. Це дозволяє боту побачити команду без вимкнення Privacy Mode.
2. В утиліті виберіть **2**. З результату візьміть ID потрібної групи разом із мінусом, наприклад `-1001234567890`.
3. Запишіть у `.env`: `TELEGRAM_CHAT_IDS='["-1001234567890"]'`. Для кількох чатів: `'["-1001234567890","123456789"]'`.
4. Виберіть **1**, збережіть згенерований `DEVICE_SECRET` у `.env`. Це спільний ключ плати та сервера. Утиліта показує новий ключ, але не змінює Cloudflare автоматично.

`WORKER_URL` заповните після створення сервера. Для тестування Worker локальний Telegram-токен не потрібний: його використовує сам сервер. Поле `TELEGRAM_CHAT_IDS` у `.env` зберігається для зручності; реальних отримувачів визначає налаштування Worker.

`.env` і `config.h` не входять до репозиторію. Кожен користувач створює власні ключі та бота.

Далі: [Cloudflare](cloudflare.md). Довідка: [Telegram Bot API](https://core.telegram.org/bots/api#getupdates).
