# Якщо щось не працює

## Немає USB-порту

Лампочка світиться навіть від кабелю, який лише заряджає. Спробуйте кабель із передаванням даних, інший USB-порт або підключення без хаба. Від’єднайте й під’єднайте плату та знову відкрийте **Tools → Port**.

Якщо порт не з’явився, визначте USB-UART чип своєї плати. Драйвер залежить від нього: [CP210x від Silicon Labs](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers) або відповідний драйвер [WCH](https://www.wch-ic.com/downloads/). Не встановлюйте випадковий драйвер до визначення чипа.

## Помилка компіляції або запису

| Помилка | Що зробити |
| --- | --- |
| `config.h: No such file` | Скопіюйте `config.example.h` у `config.h` поруч з `.ino` |
| `WiFiManager.h: No such file` | Установіть **WiFiManager by tzapu** у Library Manager |
| `conflicting declaration BOOT_PIN` | Візьміть актуальний `.ino`: у ньому назва `WIFI_SETUP_BUTTON_PIN` |
| Зависло на `Connecting…` | Затисніть BOOT, відпустіть після початку запису |
| `Hash of data verified`, `Hard resetting via RTS pin…` | Це успішне завершення, а не помилка |

Якщо змінювали файл поза Arduino IDE, погодьтеся перезавантажити його або відкрийте заново перед Verify.

## Немає Fazenda-Setup

Почекайте близько 20 секунд після запуску. Якщо плата вже підключена до збереженого Wi-Fi, окрема мережа не з’являється. Утримуйте BOOT 3 секунди після запуску та відпустіть. Подивіться Serial Monitor на **115200 baud**, якщо портал усе ще не видно.

## Немає сповіщення

1. Перевірте локальну сторінку плати: чи був успішний heartbeat.
2. У Python-утиліті виберіть **3 → 3**. Якщо `last_cron` не оновлюється, перевірте `* * * * *` у Cron Triggers. Після створення зачекайте до 15 хвилин.
3. Перевірте, що бот доданий у потрібну групу, має право писати, а `TELEGRAM_CHAT_IDS` містить саме її числовий ID.
4. Виберіть **3 → 1** і перевірте Telegram. `pending > 0` означає, що доставка ще очікує.

## HTTP та збої сервера

| Код / симптом | Перевірка |
| --- | --- |
| `401` | `DEVICE_SECRET` у Cloudflare, `.env` та `config.h` має збігатися |
| `403` | Перевірте Workers Access / правила доступу. Утиліта вже має власний User-Agent, бо стандартний Python-клієнт у нашому налаштуванні блокувався |
| `500` | Worker → Observability → Logs: перевірте `DB`, таблиці та змінні |
| `D1_ERROR: Network connection lost` | Мережева помилка Cloudflare D1. Наступний Cron може відновити роботу; технічні помилки не надсилаються в Telegram |
| Немає HTTPS-з’єднання на платі | Перевірте інтернет, доступність NTP та актуальність CA; не вимикайте перевірку сертифіката |

На macOS утиліта додає системні CA з `/etc/ssl/cert.pem`. Якщо лишається помилка сертифіката, перевірте встановлення Python та довірені сертифікати системи.

Якщо `getUpdates` повертає порожній список, надішліть нову команду `/start@USERNAME_БОТА`. Інший сервіс може забирати updates. Помилка `409` також буває при активному webhook або іншому клієнті бота.
