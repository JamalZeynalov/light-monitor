# Light Monitor — світло вдома

Невелика ESP32 у звичайній розетці повідомляє в Telegram, коли вдома зникає або повертається зв’язок. Так можна перевіряти світло вдома, навіть коли ви в іншому місці.

Плата раз на хвилину надсилає сигнал у Cloudflare. Якщо сигналів немає 2 хвилини, сервер готує повідомлення. Перевірка працює щохвилини, тому сповіщення приходить приблизно через 2–3 хвилини від останнього сигналу. Перший сигнал після відновлення запускає повідомлення «світло є».

**Втрата інтернету або Wi-Fi виглядає так само, як вимкнення світла.** Це домашній індикатор зв’язку, а не вимірювач напруги.

## Налаштування з AI-агентом

Більшість кроків у Cloudflare можна доручити Codex, Claude Code або іншому AI-клієнту з доступом до браузера. Відкрийте цей проєкт, увійдіть у свій Cloudflare та попросіть агента пройти [інструкцію](docs/ai-setup.md). Агент створить сервер, базу й розклад; доступ до акаунта та потрібні підтвердження залишаються за вами.

У цьому гайді плату прошиваємо через Arduino IDE. Тут потрібні ваш комп’ютер, USB-кабель і кілька дій у програмі.

## П’ять кроків до запуску

1. Купіть **ESP32 DevKit V1 на класичному ESP32 / ESP32-WROOM-32**, USB-кабель із передаванням даних і блок живлення. [Що саме потрібно](docs/hardware.md).
2. Завантажте проєкт через **Code → Download ZIP** та розпакуйте. Створіть Telegram-бота й отримайте ID свого чату. [Telegram і локальна утиліта](docs/telegram.md).
3. Увійдіть у Cloudflare, створіть Worker, базу D1 і щохвилинну перевірку. [Поля та кнопки](docs/cloudflare.md).
4. Відкрийте прошивку в Arduino IDE, заповніть `config.h` і завантажте код на плату. [Прошивання](docs/arduino.md).
5. Підключіть плату до домашнього Wi-Fi телефоном та перевірте вимкнення живлення. [Wi-Fi й перший тест](docs/wifi.md).

Після цього комп’ютер можна вимкнути. Плата живиться від USB, сервер працює у Cloudflare. Публічна IP-адреса, переадресація портів та SIM-карта не потрібні.

## Що надходить у чат

> 💡 Світло є! Дайте батареям 🔋 зарядитись і запускайте прання 🧺

> 🌚 Світло вимкнули. Вдома романтичний режим 🕯

Є по три варіанти для появи й зникнення світла. Для кожної події обирається один; для всіх отримувачів він однаковий. Повідомлення надходять лише при зміні стану. Технічні помилки залишаються в Cloudflare Logs. Ручний тест позначено `🧪 ТЕСТ`.

## Якщо щось не виходить

- [Немає USB-порту, не компілюється, помилки HTTP](docs/troubleshooting.md).
- [Змінити повідомлення, оновити сервер, запустити тести](docs/maintenance.md).

Код розрахований на одну плату на один Worker і до 10 Telegram-чатів. Для іншого будинку створіть окремий Worker із власною базою та ключем. Почати можна на безкоштовних тарифах Cloudflare; [ліміти й обмеження](docs/cloudflare.md#вартість).

Перевірено компіляцію та запис прошивки на класичну ESP32 DevKit V1 з пакетом ESP32 3.3.12 і WiFiManager 2.0.17. Сервер перевірено локальними тестами й на Cloudflare. Довготривалу роботу конкретної плати у вашій мережі перевірте тестом із відключенням живлення.
